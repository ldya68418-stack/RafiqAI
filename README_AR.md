# رفيق AI — مشروع أندرويد مع بناء APK تلقائي

هذا **مشروع مصدر** لتطبيق أندرويد عربي يتصل بواجهة g4f العامة عبر الإنترنت دون إدخال مفتاح API في التطبيق. لا يحتوي الأرشيف نفسه على ملف APK مبني.

## أسهل طريقة من الهاتف لإنتاج APK مجانًا

1. نزّل ملف `RafiqAI_GitHub_Build.zip` وفك ضغطه على الهاتف.
2. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا (Repository)، مثل `RafiqAI`.
3. ارفع **محتويات المجلد بعد فك الضغط** إلى جذر المستودع؛ يجب أن ترى `settings.gradle` و`build.gradle` ومجلد `app` ومجلد `.github` في الصفحة الرئيسية للمستودع. تأكد من تضمين الملفات المخفية مثل `.github`.
4. انتظر قليلًا وافتح تبويب **Actions** في المستودع. سيبدأ البناء تلقائيًا بعد رفع الملفات إلى فرع `main` أو `master`. إذا لم يبدأ، افتح `Build Rafiq AI APK` واضغط **Run workflow**.
5. افتح مهمة البناء الأخيرة. إذا كانت خضراء وناجحة، افتحها وانزل إلى **Artifacts** ثم نزّل `RafiqAI-debug-apk`.
6. فك ضغط ملف Artifacts، ثم افتح `app-debug.apk` وثبّته على أندرويد. قد تحتاج إلى السماح للمتصفح أو مدير الملفات بالتثبيت من هذا المصدر.

## إن لم يظهر Actions

افتح المستودع > **Settings** > **Actions** > **General**، وتأكد أن Actions مسموح بها. أعد فتح تبويب Actions ثم شغّل سير العمل.

## معلومات مهمة

- بناء APK يتم على خوادم GitHub Actions؛ قد تتغير سياسات أو حدود GitHub.
- g4f واجهة/مشروع طرف ثالث؛ قد تتوقف الواجهة العامة أو تتغير أو تضع حدودًا. لذلك لا يمكن ضمان خدمة مجانية بلا حدود أو استمرار عمل مزوّد بعينه.
- لا ترسل كلمات مرور أو بيانات شخصية حساسة إلى مزود عام.
- الملف الناتج `app-debug.apk` نسخة تجريبية غير موقعة بمفتاح إصدار خاص، ومناسبة للتثبيت اليدوي والاختبار.
